Review notes · measurements and interactions

This assembled concept uses a fixed 1000 × 650 section viewport to accommodate the selected pieces; the original 25 concepts remain unchanged. The summary rail from 5 is on the right, with a selected-job inspector beneath its last-X summary. Clicking a row selects the job; the ribbon also selects jobs.

Tabs filter the selected last-X window. The ribbon, sidebar summary and worklog matrix always count the complete window, not just the filtered list. “Show” in the matrix narrows the list by worklog; the outcome tab still applies. Selection follows the visible list when changing filters. A ribbon selection clears filters if necessary to reveal that job. The worklog matrix starts collapsed.

The same 50 synthetic jobs from the original gallery are ordered newest first by fixed finish time. 10 / 25 / 50 are demonstration choices, not a production default. Elapsed is root-command wall-clock runtime, not CPU time, utilization or time saved. Missing elapsed values are excluded from statistics and have no runtime bar. Bars use the longest measured job in the full last-X window, even when filtering. CPU availability and completeness are disclosed per job. Worklog / session / checkout links are local demo affordances, not fabricated real destinations.

Success = exit 0; failure = nonzero exit or launch failed; cancellation = cancelled before start or signaled with a cancellation request; unclassified = unknown. These grouping rules are design assumptions for review, not changes to production policy. Running, Queued, broker, retention and protocol are unchanged.
